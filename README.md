# Alexander Watson Counselling

Production static website for <https://alexanderwatsoncounselling.co.uk/>.

This version is deliberately dependency-free and compatible with GitHub Pages:
no framework, no build step, no external requests. The published entry point is
`index.html`; styles, script, imagery and the two self-hosted OFL typefaces are
all in `assets/`.

See `DEPLOYMENT-STEPS.txt` for the exact publishing steps.
