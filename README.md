# Alexander Watson Counselling website

A fresh Jekyll website created from the Alexander Watson Studio Website Generation Master Prompt, Standard Website Implementation Profile and supplied Practice Clarity Blueprint template.

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`.

## Review first

1. `docs/assumptions-and-confirmations.md`
2. All visible `[CONFIRM]` placeholders
3. Contact-form provider and privacy notice
4. Professional status and permission to advertise counselling services
